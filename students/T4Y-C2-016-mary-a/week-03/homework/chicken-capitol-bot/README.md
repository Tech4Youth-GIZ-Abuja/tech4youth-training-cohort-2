🍗 Chicken Capitol Customer Service Bot
​A customer service chatbot built for Chicken Capitol to help customers get instant answers to common inquiries. The project is deployed on Netlify.
​🔗 Live Demo
​Netlify Link: (https://chicken-capitol-assistant-ma.netlify.app)
​📋 What the Bot Handles
​Opening Hours: Lets customers know when Chicken Capitol is open and closed.
​Location: Shares store address and location details.
​Menu & Availability: Lists what items are currently available on the menu.
​Menu Prices: Provides pricing information for items on the menu.
​🛠️ Technologies Used
​HTML: Structures the chat interface and web page layout.
​​JavaScript: Handles user input and chooses the bot's replies in the browser.
​Python: Bot.py is a terminal version of the same bot, with the same rules.
