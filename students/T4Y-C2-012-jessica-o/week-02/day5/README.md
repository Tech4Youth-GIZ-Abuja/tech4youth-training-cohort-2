# Day 5: Python basics (class code)

These are the code files from Day 5. They are yours: open them, run them, change them.

| Folder | What's in it |
|---|---|
| `lessons/` | 18 lesson files, `01_hello.py` to `18_functions.py`. Each one ends with 3 "Try it yourself" exercises. |

| `labs/` | The lab programs: `about_me` (Lab 4), `naira_calculator` (5), `name_badge` (6), `times_table` (7), `delivery_fee` (8), `shop_menu` (9), `rule_bot` (10). |

Or in the terminal: `python lessons/01_hello.py`
