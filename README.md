# Tech4Youth Cohort 2: Student Work

This is where you hand in your **lab work** and **homework** every week.

Everyone in the class shares this one repository.
**You have your own folder.** You only put files in your folder.

---

## 1. Find your folder

Go to the **`students`** folder. Find the folder that starts with **your student ID**.

```
students/
└── T4Y-C2-007-amina-b/      ← your folder (your ID + your name)
    ├── README.md            ← about you
    ├── week-01/
    │   ├── lab/             ← lab work from class
    │   └── homework/        ← homework
    ├── week-02/
    └── ...
```

> ⚠️ **Only change files inside your own folder.**
> If you change anything outside it, a robot check will stop your work. Don't worry: it tells you what to fix.

---

## 2. Hand in your work (in the browser, no coding needed)

Example: week 1 lab, student ID **T4Y-C2-007**.

1. Open your folder, then **`week-01`**, then **`lab`**.
2. Click the **Add file** button, then **Upload files**.
3. Drag your files into the box. You can also click **choose your files**.
4. Scroll down to **Commit changes**.
   - In the first box, write what you did, e.g. `Week 1 lab: my first prompt`
   - Choose **"Create a new branch for this commit and start a pull request"**
   - Name the branch: **`week-01/T4Y-C2-007`** (the week, then a slash, then your ID)
5. Click **Propose changes**.
6. You now see the pull request page. Fill in the boxes in the description.
7. Click **Create pull request**. 🎉

### What happens next?

| You see | It means | What to do |
|---|---|---|
| 🟡 Yellow dot | The robot is checking | Wait about 30 seconds |
| ✅ Green tick + 🤖 comment | Your work arrived and is in the right place | Wait for your facilitator to review |
| ❌ Red cross + 🤖 comment | A file is outside your folder | Read the robot's comment. It names the file and tells you how to fix it |
| 🟠 **Changes requested** | Your facilitator wants a small fix | Read the comment, then fix it **on the same branch** (see section 3). Don't open a new pull request |
| ✅ **Approved** + 🟣 **Merged** | Your work is accepted and saved | Well done! 🎉 |
| 💬 Comment | Someone wrote to you | Read it and reply |

---

## 3. Fix your work, or add more files to the same submission

Your pull request stays open until it is merged, so you can keep adding to it.

1. On the main repository page, click the **branch dropdown** (it says `main`).
2. Choose **your branch**, e.g. `week-01/T4Y-C2-007`.
3. Go to your folder and upload or edit the files, like before.
4. This time choose **"Commit directly to the `week-01/T4Y-C2-007` branch"**.

Your pull request updates automatically.

---

## 4. Rules

- ✅ One branch and one pull request for each week's work. Lab and homework can go in the same one.
- ✅ Branch name: `week-0X/YOUR-ID`
- ✅ Put files in the right week folder.
- ❌ Never upload passwords, API keys or other private information.
- ❌ Never edit another student's folder.
- 🤝 You can **read** other students' work to learn. Copying is not learning.

---

## 5. Words you will hear

| Word | Simple meaning |
|---|---|
| **Repository (repo)** | A project folder that lives on GitHub |
| **Commit** | Saving your changes with a short message |
| **Branch** | Your own private copy where you work without changing `main` |
| **Pull request (PR)** | Asking: "Please add my work to `main`" |
| **Merge** | The facilitator accepts your work into `main` |
| **main** | The official version that holds everyone's accepted work |
